# Peg Hole Stabilizer (Web)

アニメ原画スキャンの **ACMEタップ穴**(スタジアム形バー2個 + 中央の丸穴)を基準に、全ページの位置・傾き・拡縮を揃えるブラウザアプリ。画像は外部に送信されません。

## 使い方 (Mac)
1. このフォルダを Mac にコピー
2. ターミナルで `bash start.command`(または Finder から開く) → Chrome が `http://localhost:8765` を開く
   - ターミナル不要なら `index.html` を Chrome で直接開いても動きます(動かなければ上の方法)
3. 画像フォルダを選択(またはドラッグ&ドロップ) → スタート
4. 出力: 入力フォルダ内の `stabilized/`。タップ未検出画像は `stabilized/_not_founds/` に元のまま入ります。`report.csv` に結果一覧。
   - Chrome/Edge: フォルダへ直接保存。Safari/Firefox: ZIPダウンロード

## 仕様
- 対象: jpg/jpeg/png/bmp。**親フォルダを選ぶと最下層まで走査し、フォルダごとに独立して**穴位置合わせ(基準ページ・キャンバスもフォルダ単位)
- 出力: 元と同じフォルダ構成で書き出し。未検出画像は各フォルダ内の未検出フォルダ(名称は画面で変更可、既定 \_not_founds\)へ
- **DPIは変更しない**: 元ファイルのJFIF/EXIF(JPEG)・pHYs(PNG)・BMPヘッダのDPI値をそのまま出力へ再現(元にDPI情報がなければ付与しない)。ファイル形式も元のまま(bmpもbmp)
- 元ファイル削除オプション: 出力に成功したファイルのみ削除(フォルダ選択時のみ有効)。出力が元ファイルの上書きになる場合は削除しない
- 基準: 検出できたページのうち最大のページ(拡縮基準・位置基準)
- キャンバス: 全ページが **欠けない** 大きさに自動拡張(最大ページ以上)
- 検出: 上辺 → (オプション)時計回り90°ずつ回して再探索。通常/白抜き、濃/薄色に対応
- 異常値(傾き>10°、拡縮が0.5〜2倍外)は誤検出とみなし `_not_founds`

## 開発・検証
`python tests/run_test.py [画像フォルダ]` → `tests/out/overlay_min.png` で重ね合わせを確認(Node と Pillow が必要)。
検出パラメータは `core.js` 冒頭の `DEFAULTS` と `classify()`。

- 鉛筆の書き込みがタップに重なっていても、細線を除去して検出。バー1本が隠れている場合は、円と反対側のバーから点対称で推定(結果表に「推定」と表示、report.csv は ok_inferred)
